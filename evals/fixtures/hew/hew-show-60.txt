#60 P2 task  CI gates: formatting, govulncheck, release dry-run, actionlint
state: open  created: 2026-07-29

### Where

.github/workflows/ci.yml, .golangci.yml

### Problem

Four gaps in CI that nothing currently guards. (1) There is no formatting gate and the tree is already drifting: gofmt -l flags internal/cli/migrate.go (trailing blank line), internal/render/json.go (struct tag misalignment from the Comments/CommentsTotal addition) and internal/render/render_test.go. golangci v2 'default: standard' is errcheck/govet/ineffassign/staticcheck/unused, so golangci-lint run will never catch this. (2) Nothing scans for vulnerabilities — dependabot bumps dependency versions on a schedule but knows nothing about Go stdlib CVEs or advisories against a currently-pinned version. (3) A broken .goreleaser.yaml or a target that stops cross-compiling is only discovered when a tag is pushed, which is the worst place to find out because the tag is already public and immutable. (4) examples/auto-triage.yml is a copy-pasteable recipe shipped to users and documented in the README, and nothing validates it; actionlint would also shellcheck the non-trivial grep/printf run: block in review-tests.yml.

### Fix

Add a formatters block (gofmt + goimports) to .golangci.yml and run golangci-lint fmt --diff in the lint job, then reformat the three drifting files. Add a govulncheck job using golang/govulncheck-action — it is call-graph-aware so false positives are rare. Add a release-dry-run job running goreleaser check plus goreleaser build --snapshot; both were verified locally and the snapshot build takes about a second. Add actionlint over .github/workflows/ and examples/auto-triage.yml. Pin every new action to a SHA, matching the existing workflows.

### Done when

- [ ] A formatters block exists in .golangci.yml and CI fails on gofmt/goimports drift
- [ ] The three currently-drifting files are reformatted and gofmt -l is empty
- [ ] govulncheck runs on pull requests and blocks on findings
- [ ] ci.yml runs goreleaser check and a snapshot build, so a broken release config fails a PR instead of a pushed tag
- [ ] actionlint lints .github/workflows/ and examples/auto-triage.yml
- [ ] Every newly added action is pinned to a SHA, not a version tag
